# 岭南游纪

岭南游纪是一个面向课堂教学和自主探索的粤港澳文化学习原型。你可以从互动地图进入「骑楼与市井」和「英歌上场前」两条路线，通过图文、方言音频和小任务了解岭南文化。无需注册，学习进度、笔记和跟读录音保存在当前浏览器，不会上传。

## 快速开始

需要 **Node.js 22.12 或更高版本**。在含 `package.json` 的项目根目录打开两个终端：

**终端 1：安装依赖并启动数据接口**

```sh
npm ci
npm run backend
```

**终端 2：依赖安装完成后，启动前端**

```sh
npm run dev
```

打开 [http://localhost:5173](http://localhost:5173)。在首页点击地图标记或从「目录 → 文化路线」进入学习；在「我的探索」查看进度。如果三维地图显示异常，可打开 [二维地图模式](http://localhost:5173/?map=svg)。

如果页面提示数据加载失败，请确认终端 1 仍在运行（后端默认端口为 `3001`）。不要直接双击打开 `index.html`。

## 构建预览

保持后端运行，在项目根目录执行：

```sh
npm run build
npm run preview
```

打开 [http://localhost:4173](http://localhost:4173)。前端产物位于 `dist/`；主应用仍依赖 `/api/seed-data`，仅托管静态文件无法完整运行。
